# asn1pp Logo Concept Design Brief

## Overview

asn1pp is an ASN.1 encoding rules library for embedded C++. The logo must convey data structure, security, and engineering precision while remaining clean and scalable across contexts from favicon to hero display.

## Symbolism

**Hexagon (Primary Shape)**
The hexagon is the core visual metaphor. In ASN.1 and data encoding, structure is paramount. The hexagon evokes:
- Cellular data structures and organized binary layout
- Honeycomb patterns representing efficiency and interconnection
- Six sides suggest stability and balance in encoding architecture
- Natural fit for embedding within a circular or square frame

**Lock/Shield Motif (Center)**
A lock or shield integrated into the center communicates:
- Data integrity and validation
- Security of encoded information
- Trust and reliability of the encoding process
- The shield formfactor works well as a subtle overlay on the hexagon

**Binary/Hex Stream (Border Flow)**
A flowing stream of binary or hexadecimal characters around or through the border represents:
- Raw data in its fundamental form
- The transformation from human-readable to machine-encoded
- Continuous data flow and processing
- Technical depth and encoding expertise

## Color Palette

**Primary: Deep Indigo #3F51B5**
- Conveys trust, engineering excellence, and professionalism
- Provides strong contrast for text and icon elements
- Feels appropriate for industrial/embedded development tools

**Accent: Amber #FFC107**
- Highlights key elements and draws attention
- Represents data, energy, and active processing
- Creates visual hierarchy without overwhelming the primary indigo

**Supporting Colors**
- White or light gray for text on dark backgrounds
- Near-black #1A1A2E for maximum contrast text
- Optional: subtle gradients from #3F51B5 to #5C6BC0 for depth

## Typography

**Primary Typeface**
- Font Family: JetBrains Mono or Fira Code (monospace)
- Reason: Reflects the code-first nature of the library
- The "pp" in asn1pp references C++ and programming lineage

**Numeric Accent**
- The "1" in "asn1pp" should be styled in amber (#FFC107)
- Creates a subtle visual anchor and reinforces data/binary theme
- Example: "asn1pp" with the "1" highlighted

**Weight and Style**
- Bold for main logo wordmark
- Regular weight for extended text
- Consider italic for taglines to add dynamism

## Size Guidelines

| Context | Dimensions | Notes |
|---------|------------|-------|
| Favicon | 16x16 | Simplified hexagon, minimal detail, single color |
| Navigation Bar | 32x32 | Small lock icon or abbreviated "a1p" mark |
| Hero Display | 200x200 | Full detail with hexagon, lock, and hex stream |
| Social Preview | 1200x630 | Landscape orientation, logo left-aligned with tagline |

**Scaling Notes**
- The hexagon shape should remain recognizable at 16x16
- At 32x32, the lock motif becomes visible but simplified
- Full lock detail and hex stream border only practical at 64x64+
- Social preview should include "asn1pp" wordmark beside logo

## Usage Contexts

**Favicon (16x16)**
- Single hexagon in indigo, possibly with small amber accent dot
- Must read clearly at small sizes in browser tabs
- ICO format with 16x16 PNG fallback

**GitHub Social Preview (1200x630)**
- Landscape layout with logo on left third
- Tagline suggestion: "ASN.1 Encoding Rules for Embedded C++"
- Dark or light theme variants for light/dark mode compatibility

**Documentation Site Header**
- 32x32 or 64x64 logo with wordmark
- Indigo background with white/amber text works well for headers
- Ensure sufficient contrast for accessibility

**Printed Material**
- Vector format (SVG) for scalability
- Consider reversed version (amber hexagon with indigo details) for dark print surfaces
- 300 DPI minimum for physical reproduction
